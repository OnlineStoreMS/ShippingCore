# OSMS 快递助手打单助手（Chrome 扩展）

从发货中心「打单发货」带入：**快递模板名、订单单号、勾选商品** → 在快递助手批打页自动勾选订单并尽量点「选择发货」、选模板；**打印由人工点击**。

## 安装（开发者模式）

1. Chrome 打开 `chrome://extensions`
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本目录：  
   `ShippingCore/extensions/kdzs-print-helper`
4. 确认扩展已启用

## 使用

1. 打开发货中心待发货 → 打单发货 → 选「快递助手」→ 选模板 → 勾选商品  
2. 点「打开快递助手」  
3. 新开的快递助手页右下角出现「OSMS 打单助手」面板，并自动执行选单  
4. **人工确认模板/商品后点打印**  
5. 回发货中心「同步单号」→「确认发货」

若页面结构有变导致点不到按钮：在面板点「执行选单」重试，或按提示手工点「选择发货」。

## 权限说明

- 读写 `chrome.storage`：暂存发货中心传来的任务  
- 访问发货中心域名与 `*.kdzs.com`：页面桥接与自动化  

## 注意

- 快递助手是 SPA，DOM 可能升级；自动化为启发式，不能保证 100%  
- 不会自动点「打印」  
- 任务约 30 分钟过期，需重新从发货中心打开
