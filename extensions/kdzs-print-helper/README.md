# OSMS 快递助手·电脑版（Chrome 扩展）

目录：`extensions/kdzs-print-helper` · 版本 **2.0.1+**

## 能力（仅此）

1. 发货中心页面桥（`shipping-bridge`）接收 handoff  
2. 消费 `_osms_ht` 云端 token  
3. 打开快递助手 → 勾选订单 / 选模板  
4. **到此结束**，人工点打印（无配对、无自动打印/发货）

## 不含

- OpsMobile 配对 / 心跳 / 领任务  
- 打印机选择 / 自动打印 / 自动发货 / 任务回执  

手机远程请用：`extensions/kdzs-print-mobile`（勿与本扩展同时启用）。

## 安装

Chrome → 开发者模式 → 加载本目录 → 名称应为 **OSMS 快递助手·电脑版**。
