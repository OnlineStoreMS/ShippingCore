# OSMS 快递助手打单助手（Chrome 扩展）

## 能力

1. **绑定手机**：电脑扩展生成配对码 → 手机 OpsMobile 输入绑定  
2. **在线心跳**：约每分钟上报，手机可看插件是否在线  
3. **远程领任务**：门户进打单发货 → 顶栏切平台 → 勾选 → **自动打印快递单并发货**  
4. **兼容旧链路**：发货中心「打开快递助手」仍可用（`_osms_ht` token）

> 领任务：Service Worker 存活时约 **12 秒**一轮；休眠后靠 1 分钟闹钟唤醒。弹窗可点「立即领任务」。  
> 打印弹层会处理：已打印确认、选单号、选打印机；发货默认「普通发货」。

## 安装

1. Chrome → `chrome://extensions` → 开发者模式  
2. 「加载已解压的扩展程序」→ 本目录  
3. 确认版本 **1.3.0+**；改代码后点「重新加载」

## 配对

1. 电脑点扩展图标 → **生成配对码**  
2. 手机 OpsMobile → **快递助手插件** → 输入配对码 → 绑定  
3. 扩展显示「在线」后，手机打单页可选该设备发送任务

## 打单路径（与人工一致）

1. `df.kdzs.com` 顶栏「订单 / 推送订单」→「打单发货」（扩展用 `#/batchPrint?platform=…`）  
2. 顶栏切换平台：抖音=`fxg`、淘宝=`tb`、手工订单=`dfhand`  
3. 批打 iframe 内：下单时间 → 查询 → 勾选 → 选模板（不自动点打印）

## 权限

- `storage` / `alarms` / `tabs`  
- host：`*.kdzs.com`、`*.zfcycle.com`
