# OSMS 快递助手打单助手（Chrome 扩展）

## 能力

1. **绑定手机**：OpsMobile 生成配对码 → 扩展弹窗输入绑定  
2. **在线心跳**：约每分钟上报，手机可看插件是否在线  
3. **远程领任务**：手机选模板发送打单 → 扩展领取并在已打开的快递助手页自动勾选  
4. **兼容旧链路**：发货中心「打开快递助手」仍可用（`_osms_ht` token）

> 打印仍建议人工点「打印快递单」（更稳）；自动化负责勾选订单/模板。

## 安装

1. Chrome → `chrome://extensions` → 开发者模式  
2. 「加载已解压的扩展程序」→ 本目录  
3. 确认版本 **1.1.0+**；改代码后点「重新加载」  
4. 长期打开一个已登录的快递助手窗口

## 配对

1. 手机 OpsMobile → **快递助手插件** → 生成配对码  
2. 点扩展图标 → 输入配对码 → 绑定  
3. 状态显示「在线」后，打单页可选该设备发送任务

## 权限

- `storage` / `alarms` / `tabs`  
- host：`*.kdzs.com`、`*.zfcycle.com`
